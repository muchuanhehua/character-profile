# 角色档案

根据资料与用户决定，创建或修改结构化角色档案。

## 基本规则

- 严格按照 `references/character-profile-template.md` 创作。以每个 `###` 为一步，其下的 `####` 随所属模块处理；每次只推进当前模块，确认后才能写入并继续。
- 明确区分资料事实、合理推演和用户决定。无法确定的内容应留空、标记“待用户确认”或与用户讨论，不得自行补全。

## 资料取材

- 始终读取 `references/character-profile-template.md`。
- 使用官方资料时，从 `references/official-source-rules/` 中读取与当前作品对应的规则文件。各作品规则相互独立，不得引用、合并或类推其他作品的页面结构与模块定义。
- 不存在对应作品的取材规则时，先向用户说明并确认取材方式。
- 使用官方资料时，先确认角色词条与可用资料，列出可提取模块，等待用户确认取材范围后再整理内容。
- 处理成人私密模块时，读取 `references/nsfw-guide.md`。

## 工作流程

1. 确认任务是创建还是修改，并确认角色、所属作品、资料来源和已有文件。
2. 按“资料取材”读取所需文件，收集并整理当前任务需要的资料。
3. 创建角色档案时：
   - 按模板顺序处理各模块。
   - 先给出当前模块的资料分析、推演方向和草稿，并围绕需要确认、存在分歧或值得深化的内容与用户探讨；必要时提出一至三个关键问题。
   - 用户确认当前模块或回复“继续”后，将其写入文件，再处理下一模块。
4. 修改角色档案时：
   - 读取现有档案，定位受影响模块。
   - 展示修改预览，并与用户讨论修改方向及关联影响。
   - 获得确认后，只更新对应模块。
